# Точность классификатора зон

Создано автоматически командой `python src/train_zones.py` (2026-11-18). Не править руками.

## Итог

**Accuracy на отложенной выборке: 97.4%** (39 точек). Цель issue #11 (≥ 75%) достигнута по этой оценке; ограничения ниже.

**Но на поле, которого модель не видела, точность ниже 75%: field_2, field_3 (раздел «Проверка по полям»).**

## Предупреждения

- Класс **salinity**: в проверке только 4 точек (меньше 5), его F1 ненадёжен, одна ошибка меняет его сильно.
- Класс **water**: 0 размеченных точек, классификатор его не знает и никогда не предскажет.
- Класс **salinity**: ни одна из 16 точек не лежит в рисовом массиве (весной там воды не было). Зоны считаются только внутри массива, поэтому на картах этот класс почти не появится.
- Класс «соль» (salinity) размечен по виду на снимке (белые и светлые пятна), без проверки на месте: наземных измерений засоления у нас нет.
- Деление на обучение и проверку случайное по точкам. Соседние точки одного поля похожи друг на друга, поэтому на новых полях точность может быть ниже, чем здесь.
- Метки ставил один человек по снимку июля 2025; точность считается относительно этих меток, а не относительно реального состояния поля.

## Проверка по полям (строже)

Модель учится на двух полях и проверяется на третьем: так видно, как она работает на поле, которого не знала. Это и есть главный вопрос для любого нового поля.

| Проверочное поле | Точек | Accuracy | Классов нет в обучении |
|---|---|---|---|
| field_1 | 37 | 94.6% | - |
| field_2 | 37 | 67.6% | - |
| field_3 | 79 | 69.6% | salinity |

**Ниже 75% на полях: field_2, field_3.** На новых полях цель по этой оценке не достигается; случайное деление выше оптимистично (соседние точки одного поля похожи).

## Данные и модель

- Точек разметки в файлах: 180, в обучение и проверку пошло: 153.
- Признаки (13): ndvi_05, ndwi_05, si_05, lswi_05, ndvi_07, ndwi_07, si_07, lswi_07, ndvi_08, ndwi_08, si_08, lswi_08, flooded_spring.
- Классификатор: RandomForest (scikit-learn 1.7.2), 200 деревьев, class_weight=balanced, random_state=42.
- Деление: 75% обучение / 25% проверка, со стратификацией по классам.
- Модель: `models/zones.joblib`, 481 КБ.
